# حجوزاتي – Android

**الإصدار:** 1.6.0 (Debug)

## الميزات والإصلاحات

- جدول حجوزات أسبوعي وتقويم شهري، مع الحجوزات العادية والثابتة.
- منع تعارض الحجوزات العادية والثابتة، وعرض وقت بداية الحجز فقط بصيغة 12 ساعة.
- تخزين محلي عبر SQLite مع ترقية قاعدة البيانات من الإصدار 5 إلى 6 دون حذف بيانات المستخدم.
- بطولات الدوري من مرحلة واحدة والذهاب والإياب.
- بطولات المجموعات: توزيع الفرق إلى مجموعات، مباريات ذهاب واحد داخل المجموعة، ترتيب بالنقاط وفارق الأهداف، وتأهل أول فريقين من كل مجموعة.
- بطولات خروج المغلوب: إنشاء الأدوار المتتابعة، معالجة التأهل التلقائي عند العدد الفردي، والتحقق من اكتمال النتائج قبل إنشاء المرحلة التالية.
- ربط إحصائيات اللاعب بأحد فريقي المباراة والتحقق من عدم إدخال قيم سالبة.
- ربط حجوزات المباريات بالبطولات، وتنظيف الارتباط عند حذف الحجز أو إعادة القرعة أو حذف البطولة.
- مزامنة أسماء الفرق مع المباريات والحجوزات عند تعديل الاسم، وحماية السجلات التاريخية من حذف فريق مشارك في مباريات محفوظة.
- تحسين أحجام الأزرار والمسافات للهواتف الصغيرة وإضافة عناوين أيام التقويم الشهري.

## البناء

يُبنى التطبيق عبر GitHub Actions باستخدام Gradle 8.7 وJava 17. ينتج ملف Debug APK قابل للتثبيت للاختبار. هذا ليس إصداراً Release موقعاً للنشر على المتجر.
